## 🧩 How I Think About Development

I don't want to simply become someone who knows a lot of frameworks.

I want to understand the layers underneath them.

```text
        PRODUCT
           ↓
       FEATURES
           ↓
      ARCHITECTURE
           ↓
       BACKEND / API
           ↓
      SYSTEM DESIGN
           ↓
     FUNDAMENTALS
           ↓
       THE MACHINE
```

That's why I'm constantly moving between **application development, backend engineering, AI systems, developer tooling, and lower-level technologies**.
