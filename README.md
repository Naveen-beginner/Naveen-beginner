## 🚀 What I'm Building

### 🧠 THE - ABANDONED IDE

**An AI-powered development environment built to make the IDE itself intelligent.**

> **Intelligence starts at the ground level — the IDE itself.**

Most AI coding experiences begin with a prompt. **THE - ABANDONED IDE** takes a different approach: the development environment provides the AI agent with structured context from the project, files, user actions, and development workflow before the agent acts.

This creates a tighter loop between **developer → IDE → backend → AI agent → tools → project**.

```text
Developer
    ↓
THE - ABANDONED IDE
    ↓
Project Context + User Intent
    ↓
Backend & AI Orchestration
    ↓
Gemini AI Agent
    ↓
Tools → Files • Commands • Project
    ↓
Action / Result back to the IDE
```

The project explores how **AI agents can become an integrated part of the development environment**, rather than simply another assistant sitting beside the code editor.

**⚡ Built with:** Flutter • Dart • Node.js • Express.js • MongoDB • Gemini • Google ADK • AI Agents
